# Генератор безопасных паролей

## Описание
Консольное приложение на Java для генерации надежных паролей с гибкими настройками. Программа позволяет пользователю выбирать длину пароля и типы используемых символов, обеспечивая высокую криптостойкость за счет обязательного включения каждого выбранного типа символов.

## Особенности
* **Гарантированная сложность:** Алгоритм гарантирует, что в пароле будет как минимум один символ из каждой выбранной категории (строчные, заглавные, цифры, спецсимволы).
* **Валидация данных:** Обработка некорректного ввода (длина пароля, пустой набор символов) с использованием исключений (`IllegalArgumentException`).
* **Логирование:** Все этапы работы — от запуска до ошибок генерации — записываются в журнал через **Apache Log4j**.
* **Перемешивание (Shuffle):** Для исключения предсказуемости позиций символов используется алгоритм случайного перемешивания итоговой строки.

## Технологии
* **Язык:** Java (JDK 8+)
* **Библиотеки:** Log4j 1.2.17
* **Среда разработки:** IntelliJ IDEA

## Структура кода
* `Main.java` — Взаимодействие с пользователем, чтение консольного ввода и конфигурация логгера.
* `Generator.java` — Основная логика: формирование пула символов, сборка обязательной части и итоговое перемешивание.
* `Password.java` — Класс-оболочка (POJO), демонстрирующий принцип инкапсуляции данных.

## Запуск
1. Убедитесь, что библиотека `log4j-1.2.17.jar` добавлена в Project Structure (Libraries).
2. Разместите файл `log4j.properties` в папке с ресурсами или корнем проекта.
3. Запустите класс `Main`.
